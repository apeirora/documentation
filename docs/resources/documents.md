# Documents

In this area you can find a collection of useful resources on Apeiro.
These documents may be used as-is for presentations on Apeiro.
We use them ourselves and share them here to enable everyone to share the Apeiro vision and purpose.

## General Apeiro

- [Apeiro Reference Architecture Overview](/assets/resources/documents/20250508-SAP-OSS-Webinar-Apeiro.pdf) (May 2025) - this slide deck explains the overall value and vision of the IPCEI project, 8ra, and Apeiro in the context of open source.

- [Data Center Observability Blueprint](/assets/resources/documents/Apeiro_DataCenterObservability_Blueprint_20260130_ext.pdf) (Jan 2026) - this document outlines a blueprint for an open-source data center monitoring and
observability platform, based on Apeiro Reference Architecture.

- [Running Rook at Petabyte Scale Across Multiple Regions](https://www.clyso.com/eu/media/pages/products/rook/144058f243-1785224164/white-paper-rook_10072026.pdf) (Jul 2026) - a technical whitepaper by [Clyso](https://www.clyso.com/) on deploying a digitally sovereign storage backbone for Europe, describing how Rook manages a multi-region Ceph fleet at petabyte scale as part of the Apeiro Reference Architecture.
